# 個人投資規劃系統

依 `投資試算表_2026-2048.xlsx` 重建的桌機與行動版投資規劃網站。兩個入口共用 `shared/core.js` 計算核心與同一份瀏覽器設定。

- 桌機版：`web/index.html`
- 手機版：`mobile/index.html`
- GitHub Pages 桌機版：https://weichihung.github.io/investment-plan/
- GitHub Pages 手機版：https://weichihung.github.io/investment-plan/mobile.html

## 功能分頁

1. 逐年總表
2. 財務自由檢視
3. 設定
4. 持股現況
5. 投資計畫
6. 價格與配息
7. 持股推估
8. 月配息

## 主要規則

- 預設試算期間為 2026 年 43 歲至 2048 年 65 歲。
- 2026 年依目前月份自動滾動計入月份；完整年度薪資按 14 個月計，65 歲當年停止薪資。
- 預設採附檔逐年手動投資計畫，也可切換為 2028 年起的現金目標自動配置。
- 購車預設為 2030 年、總價 2,000,000 元、頭期款 50%、零利率及 40 期。
- 購車頭期款優先出售 00919；任何賣股都會同步減少持股、市值與後續股利。
- 銀行存款年底下限為 650,000 元。
- 股利以年初持股與當年度每股配息估算，最新配息資料先折減 20%；當年度新買進部位不計入當年股利。
- NVDA 以最新一期官方季度配息年化後再折減 20%，避免過渡年度的新舊配息平均低估後續年度。
- 報價更新使用 Yahoo Finance 完成交易日資料；配息優先核對投信或公司官方資料。
